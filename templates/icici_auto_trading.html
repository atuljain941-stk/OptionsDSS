Broker Positions (live from ICICI)

Everything currently held in the account, whether opened through this page or not. Rows already covered by a tracked position are marked; select untracked ones to adopt them for P&L monitoring / auto-close.
⚠ Side (LONG/SHORT) is a guess from ICICI's raw quantity sign, and it's been confirmed wrong on a real vertical (a bull put spread came back with both legs marked LONG). Check each row's Side dropdown against what you actually know the position to be, and correct it before adopting -- the dropdown is editable, don't trust the default.
To set target/stop-loss for a whole strategy (not per leg): check every leg that belongs to that one strategy (e.g. both legs of the NIFTY vertical together), enter ONE target and ONE stop-loss below, click Adopt. That single target/stop-loss then applies to the combined P&L across all the legs you selected -- exactly the "strategy level, not position level" behavior. Adopting BankNifty and the NIFTY vertical separately (two Adopt clicks) gives each its own independent target/stop.

Open New Position

Safe Sequential (default): each leg's fill is confirmed before the next is placed — never a moment of naked short exposure, but a small delay between legs (a poll loop, up to 5s per leg) where price can move. Simultaneous Market: every leg fires as a market order back-to-back with no wait — minimal time between legs so minimal slippage risk, but gives up the never-naked guarantee if one leg's order gets rejected after the other has already gone out. Only use Simultaneous on liquid instruments (NIFTY/BANKNIFTY weekly ATM strikes) where near-instant fill is a safe assumption.

Open Positions

A background job polls combined P&L for every OPEN position every 30 seconds and, if target or stop-loss is hit, fires the closing order automatically using the same safe sequencing as a manual close (SHORT legs bought back first, then LONG legs sold). "Check P&L Now" above runs that same check immediately instead of waiting for the next tick.

Strategies

Enabled strategies are checked automatically every minute (each strategy's own eval interval further throttles how often its condition is actually re-evaluated). When a strategy's opening condition is met, it resolves ITM/ATM/OTM legs against live spot + the chain and fires a tracked position with the target/stop-loss and execution mode defined here.
