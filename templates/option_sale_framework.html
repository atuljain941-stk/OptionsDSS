🧭 Option Sale Framework

Sequential 7-stage evaluation, run in this exact order: market/sector regime → weekly trend → daily setup → IV vs HV → expected move/strikes → trade structure/risk → beta/correlation sizing. Every stage runs regardless of how earlier ones look — this is a complete picture to weigh, not an automated kill-switch. Stage 7 is explicitly a sizing filter, not a go/no-go gate.
