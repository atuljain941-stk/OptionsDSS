# Scanner Columns Sortable UI v74

Changes included in this build:

- Removed the left/right `<` and `>` reorder controls from Scanner Builder result-column chips.
- Column-template chips are reordered by drag and drop only; save the template to persist the order.
- Increased Scanner Builder and Scanner Dashboard font sizes for better readability.
- Scanner Builder result tables are sortable by clicking any column header.
- Scanner Dashboard tile result tables are sortable by clicking any column header.
- Dashboard tile sort order is retained with the tile layout when the dashboard is saved.
- Column templates remain primitive/expression based and are still shared between Scanner Builder and Scanner Dashboard.
